## Direct Answer

防火门（fire-rated door）的硬件不是"越结实越好"，而是**必须通过认证、并且满足 NFPA 80 的两条硬要求**：

1. **Self-Closing（自动关闭）**——门必须能从任意开位自动关回。
2. **Self-Latching（自动锁舌）**——关门后锁舌必须自动伸进 strike，卡住门。

一句话：**防火门的"安全"不来自锁有多结实，而来自"门能不能在火灾时自己关紧并锁上"。** 这两条是 NFPA 80 年度检查里最常见的失败点。

---

## 最关键的区分：Panic Hardware ≠ Fire Exit Hardware

这是消防检查里**最常见的错误认知**（IBC/NFPA80 视频原文强调）：

| 维度 | Panic Hardware（逃生推杆） | Fire Exit Hardware（防火逃生） |
|---|---|---|
| 目的 | 快速逃生（人多时推门而出） | 防火 + 逃生 |
| 适用 | 依 occupancy / 人流量决定 | 防火门强制 |
| **Mechanical Dogging** | ✅ 允许（可卡住保持常开） | ❌ **禁止** |
| 认证 | 逃生设备认证 | 必须 **listed + labeled 用于防火门** |

**关键红线**：fire exit hardware **不允许 mechanical dogging**（把推杆卡住、让门保持常开）——因为防火门必须能**自动关闭 + 锁定**。用普通 panic hardware（带 dogging）装在防火门上，是典型检查失败。

---

## 为什么 "Self-Closing + Self-Latching" 是命门

NFPA 80 §6.4.4.1 要求防火门 self-closing + self-latching。背后的逻辑：

- 火灾时，门关上才能挡住火和烟；
- 门不光要"关上"，还要"锁舌伸进 strike 锁住"，否则烟一推就开。

**因此下列都是违规**（CDF Distributors 明确列出）：

1. **Roller latch（滚轮锁舌）**、**磁性碰扣**、**球扣** → 不符合"positive latching"（正锁舌），防火门禁用。
2. **Mechanical dogging** → 让锁舌不伸，违反 self-latching。
3. **拆除/停用 door closer** → 违反 self-closing。
4. **用楔子/门挡/链条撑开门** → 禁止（除非用认证的电磁 hold-open 装置 + 消防联动）。

## 硬件认证：label 是命根子

NFPA 80 要求防火门上**每一个组件**（铰链、closer、锁具、exit device、flush bolt）都必须是 **listed + labeled 用于防火门**：

- **替换非 listed 硬件 = 直接 void 防火评级**。
- **消防标签（fire label）被涂漆/损坏 = 评级作废**，需原厂或认证机构重新贴标，或整门更换。
- **现场钻孔/切割/改动** = 未授权改动，同样 void 评级。

一句话：**防火门的评级，是由"全套认证硬件 + 完好标签 + 无现场改动"共同维持的，缺一即失效。**

## The Author's Take

**我的判断：防火门硬件是锁匠/门五金行业里"合规风险最高、最容易翻车"的领域之一，因为它赌的不是技术，而是人命安全。** 三点：

1. **别把 panic 和 fire exit 当一回事**——这是检查员最常抓的错。带 dogging 的普通逃生推杆装防火门，等于亲手拆掉了防火门的防火功能。锁匠装门时务必确认手上是"fire exit hardware"（listed for fire door）还是普通 panic。
2. **"positive latching"是底线，别用滚轮/磁扣糊弄**——很多人为省钱或图方便用 roller latch，但这不满足 NFPA 80 的正锁舌要求。防火门必须用 listed cylindrical/mortise 锁具或 fire exit hardware。
3. **现场改动 = void 评级**——防火门不是普通门，不能随便钻孔、切边、换非认证零件。任何物理改动前，先查 listing 是否允许。改错了，等于把一扇"防火门"变成"普通门"。

结论：**装/修防火门的锁匠，第一原则是"认 label + 满足 self-closing/self-latching + 绝不现场乱改"，而不是"把锁换得更高级"。** 防火门的价值在"合规"，不在"锁的等级"。

（以上是基于 NFPA 80 公开要求 + CDF Distributors/门五金行业资料的专业判断，非官方法规意见。具体执法以当地 AHJ 为准。）

## FAQ

**Panic hardware 和 fire exit hardware 一样吗？**
不一样。fire exit hardware 是经认证用于防火门、且不允许 mechanical dogging 的逃生硬件。

**防火门能用 roller latch 吗？**
不能。NFPA 80 要求 positive latching（正锁舌），滚轮锁舌/磁扣/球扣都不符合。

**防火门的标签涂漆了怎么办？**
评级作废。标签不能现场补，需原厂/认证机构重新贴标，或整门更换。

**防火门要多久检查一次？**
多数辖区要求 annual（每年）检查，查 label、closing、latching、无现场改动。
