## Direct Answer

Lever tumbler lock（杠杆锁）是**用一叠杠杆（lever）+ 挡块（bolt stump）挡住锁舌**的机制，而不是用销钉。正确钥匙把每片杠杆抬到精确高度，让每片杠杆上的**门槽（gate）**对齐成一条通道，锁舌挡块才能滑过去。

它是**最古老的现代安全锁原理之一**——1778 年由伦敦锁匠 Robert Barron 发明（专利 BP1200），奠定了所有现代机械安全锁的"双动活动挡块（double-acting movable detainer）"原则。

今天它的主战场是：**英国住宅前门（5-lever BS3621 标准）、保险柜（safe）、银行保管箱、监狱门**。

---

## 机制：杠杆 + 门槽 + 挡块

Lever lock 由三组核心元件构成：

1. **杠杆（Lever）**：一叠扁平金属片，绕同一根轴枢转，每片被弹簧压在"锁定"位。
2. **门槽（Gate）**：每片杠杆上开的一个槽口。钥匙把每片杠杆抬到不同高度，只有所有门槽对齐成一条水平通道时，锁舌才能通过。
3. **挡块 / 栅栏（Bolt Stump / Fence）**：固定在锁舌上的小立柱，只有当所有门槽对齐时，挡块才能穿过通道，带动锁舌收回/伸出。

**关键："双动"（double-acting）**——杠杆抬得不够或抬过头，都会挡住挡块。这是 Barron 发明的核心，也是它和老式单动锁的区别。

钥匙通常是 **bit key（有齿钥匙）**，高端保险柜锁用 **double-bitted key（双面有齿）**。

## 为什么它被用于英国前门和保险柜

### 1. 英国 BS3621 标准
英国住宅前门锁的法定/保险标准是 **BS3621**，典型配置是 **5-lever mortice**。这根标准的存在，让 lever lock 在英国住宅市场占据主导地位。BS3621 锁通常还带：
- 硬化螺栓 + 金属板（抗钻）
- 抗撬特性

### 2. 保险柜场景：false notches + curtain + relocker
高端 lever lock（尤其保险柜）靠多层防护：

| 防护 | 作用 |
|---|---|
| **False Notches（假槽）** | 类似弹子锁的 spool pin，卡住挡块制造假反馈 |
| **Curtain（帘幕）** | 钥匙一转动就封住钥匙道，阻绝 2-in-1 撬锁器伸入 |
| **Relocker（重锁器）** | 暴力/爆破破坏时自动触发二次锁定 |
| **Serrated false notches** | 大量锯齿假槽，让试探性撬锁几乎不可能 |

保险柜里的 lever lock 通常装在门内、受结构保护，且连接 relocker，对暴力破坏有额外防线。

## Lever vs Pin Tumbler（机制对照）

| 维度 | Lever Lock | Pin Tumbler Lock |
|---|---|---|
| 阻挡元件 | 扁平杠杆 + gate | key pin + driver pin |
| 钥匙 | bit key / 双面带齿钥匙 | 边缘齿钥匙 |
| 常见用途 | 英国 mortice 锁、保险柜、杠杆挂锁 | 门、deadbolt、大多数挂锁 |
| 安全升级 | 更多杠杆、false gates、curtain | 安全销、紧公差、限制 keyway |
| 地区分布 | 英国/欧洲/南美防盗门、保险柜 | 全球主流 |

**一个反直觉的事实**：高质量 lever lock 可以比基础 pin tumbler 难撬得多；但一个廉价 2-lever 锁，可能又比一个做工好的 6-pin cylibder 容易撬。**安全等级不是由"机制类型"决定的，而是由"做工 + 杠杆/销钉数量 + 防护层"决定的。**

## The Author's Take

**我的判断：lever lock 是最被低估的机制之一，尤其在北美语境下。** 很多人因为"它看起来很老"就认定它不如现代 pin tumbler，但实际上，一个 5-lever BS3621 的英国前门锁，其抗撬水平往往高于普通住宅弹子锁，保险柜里的高端 lever lock 更是机制安全的天花板之一（false notches + curtain + relocker 的组合）。

但它也有自己的应用边界：**lever lock 体积更大、不适合紧凑的 cylinder 场景**，所以它在英国住宅门和保险柜里强势，在北美住宅门（偏好紧凑 cylinder）里反而少见。

结论：**选锁时，别被"新/旧"误导，要看具体配置和标准。5-lever BS3621 是硬标准，保险柜 lever lock 是硬安全，它们和 Abloy disc detainer 一样，都属于"机制天花板"那一档。**

（以上是基于机制分析 + BS3621 标准 + 锁匠行业共识的专业判断，非我方实测。）

## FAQ

**Lever lock 是什么？**
用杠杆 + gate + bolt stump 挡锁舌的机制，1778 年 Robert Barron 发明，是弹子锁之外的另一大现代机械锁体系。

**Lever lock 安全吗？**
取决于配置。5-lever BS3621（英国前门标准）和保险柜 lever lock 很高，廉价 2-lever 锁则很弱。

**为什么英国门锁用 lever lock？**
英国有 BS3621 的 5-lever mortice 传统标准，且保险市场高度绑定这一标准。

**Lever lock 和 pin tumbler 哪个安全？**
不能笼统比。高质量 lever lock 强于基础 pin tumbler，廉价 lever lock 弱于好弹子锁。看具体做工和数量。
