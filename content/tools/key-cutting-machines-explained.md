## Quick Answer

Key cutting machines fall into two fundamental types, each mapped to a different task: a **code machine (origination machine)** cuts an original key from a numeric **bitting code** with no physical key present, while a **duplicator** traces an existing key to produce a copy. A second, independent dimension — whether the key is **edge-cut** or **high-security (side-milled / laser-cut)** — decides what machine and tooling you need.

One line: **lost the key but know the code → use a code machine; have the key and need a backup → use a duplicator.** The two are nearly non-interchangeable, and a professional locksmith usually needs both.

---

## Definition

A **key cutting machine** is a machine tool that removes material from a **key blank** to produce the cuts (bitting) that match a specific lock. **Origination** machines cut from a numeric code; **duplicators** trace a physical key. A **key blank** is the uncut metal key body whose keyway profile, shoulder, blade, and bow must match the target lock before any cutting happens.

---

## Dimension One: Origination vs Duplication

### Origination (Code Machine)

Cuts an original key from a numeric code, with **no physical key needed**. Suited to "all keys lost but the lock has a code on record" scenarios.

Three types:

| Type | Principle | Representative machines | Characteristic |
|---|---|---|---|
| **Manual** | Hand-set depth & spacing dial, cut depth by depth | HPC Blitz, Framon #2 | No computer, decades-old, precise but slow |
| **Automatic** | Software-driven cutting | Silca Futura (Edge/Pro/Auto), Keyline Gymkana, Laser Key Products 3D Extreme | Precise, low-effort, handles complex cuts |
| **Punch** | Stamped/formed (Blue Punch style) | Pro-Lok Blue Punch | Suited to bulk same-spec keys (master systems) |

### Duplication (Duplicator)

Traces an existing key to copy it. **Fast and simple, but requires a physical key.** Representative models: Ilco Flash 008 / Silca Compact, HPC Mini Speedex. Nearly all standard key blanks can be duplicated.

**The key distinction**: a code machine cuts an original key (slow work), while a duplicator can't cut from code at all — so professionals usually keep both. Manufacturers such as HPC alone span at least 5 code cutters, 6 duplicators, and 3 tubular machines.

## Dimension Two: Edge Key vs High-Security Key

| Key type | Representative blank codes / models | Machine needed |
|---|---|---|
| **Edge style** | SC1/SC4, KW1/KW10, Y1, WR5, H75, Y11 | Standard key machine (origination & duplication) |
| **High-security** | HO01, LEX90, B119 | Machine supporting side-milled / laser profiles |

High-security keys usually have **side-milled** or **laser-cut** profiles, requiring machines that support the corresponding cutter type and tool path. Dedicated high-security machines include the **Silca Matrix** and **Silca Swift** (manual high-security duplicators) and the **Silca Futura Auto/Pro** or **Keyline Gymkana** (automatic high-security origination). This is a separate capital line item from edge-cut machines.

## Depth & Spacing: The Numbers Behind "Cutting to Code"

Code cutting is governed by two geometric specs per key family — **depth increment** (how far each successive cut drops) and **spacing** (distance between adjacent cut centers), plus **MACS** (maximum adjacent cut difference):

| Key family | Depth increment | Cut-center spacing | MACS | Theoretical combinations |
|---|---|---|---|---|
| **Schlage (SC1, 5-pin × 10-depth)** | 0.015" | 0.156" (0.231" to first cut) | 7 | 10⁵ = 100,000 |
| **Kwikset (KW1, 5-pin × 6-depth)** | 0.023" | 0.150" | — | 6⁵ = 7,776 |
| **Weslock** | 0.0156" | 0.156" (0.220" to first cut) | 5 | — |

These numbers explain why Schlage and Kwikset feel different to work with: Schlage's finer 0.015" depth increment means a code machine must resolve shallower steps, while Kwikset's coarser 0.023" increments are more forgiving of worn cutters. A dull or mis-calibrated machine shows its error first on fine-increment systems.

## Key Blanks: The Pre-Cutting Step

Cutting isn't the first step — **choosing the right key blank** is. A key blank is the uncut metal key body; its:

- **keyway** (the profile of the grooves): decides whether it can be inserted into a given lock;
- **shoulder / blade / bow**: all standardized.

Common residential blanks: Kwikset (KW1, and the 6-cut KW10), Schlage (SC1, and the 6-cut SC4), Yale (Y1), Weiser (WR5). Blank material is typically **brass or nickel silver**, with nickel silver offering better wear resistance.

**Blank-selection rule**: test-insert the blank before cutting to confirm it slides smoothly into the plug — if it won't go in or binds, you've picked the wrong keyway. This step saves significant waste and time.

---

## Maintenance, Calibration & Failure Modes

Key machines are metrology tools: a drift of a few thousandths of an inch produces keys that don't turn.

- **Failure mode 1 — dull/worn cutter**: cutters (typically carbide) wear and start cutting shallow or ragged. Replace on a schedule, not only when keys fail.
- **Failure mode 2 — mis-calibration**: machines drift over time; manufacturers supply calibration blocks/keys and a calibration routine. Recalibrate after cutter changes and periodically.
- **Failure mode 3 — dirty jaws/debris**: brass shavings in the jaws cause mis-seated blanks and inconsistent cuts.
- **Maintenance routine**: keep clean and dry, lubricate per manual, replace cutters regularly, verify with a known-good key after calibration.

## The Author's Take

**My position: in key cutting, the beginner rarely gets stuck on "can't cut" — they get stuck on "didn't distinguish origination from duplication, and didn't pick the right blank."** Three points:

1. **Origination and duplication are two businesses, not one "do-it-all" machine** — a code machine cuts originals very slowly, and a duplicator can't cut from code. Expecting one machine to cover both usually means it does neither well.
2. **High-security keys are a separate ecosystem** — if you serve automotive or commercial high-security locks, budget for machines supporting side-milled/laser profiles (Silca Matrix/Swift class); that's a major line item, not an accessory.
3. **Blank selection is more fundamental than cutting** — pick the wrong blank and a perfectly-cut key is still scrap. Learn to read the keyway and select the blank before chasing cutting precision.

(Reasoning: origination vs duplication map to two non-interchangeable machine families; high-security tooling is a distinct capital class; blank keyway match is a hard prerequisite to any cut. This is professional judgment based on locksmith key-cutting industry practice and machine-classification norms, not empirical testing.)

## FAQ

**What's the difference between a code machine and a duplicator?**
A code machine cuts an original from a numeric code with no physical key; a duplicator traces an existing key. Different tasks — professionals usually need both.

**What is a key blank?**
An uncut key metal body with a specific keyway profile. Selecting the right blank is the critical pre-cutting step.

**Do high-security keys need a special machine?**
Yes. Side-milled/laser profiles need a machine supporting the corresponding cutter and tool path.

**What do "depth" and "spacing" mean in key cutting?**
Depth increment is the drop between successive cuts (e.g., Schlage 0.015", Kwikset 0.023"); spacing is the distance between adjacent cut centers (Schlage 0.156").

**How do I keep a key machine cutting accurately?**
Replace cutters on schedule, calibrate after cutter changes, keep jaws clean of debris, and verify with a known-good key.
