## Direct Answer

Key cutting machines fall into two fundamental types, each mapped to a different task:

1. **Code machine (origination machine)**: cuts an original key from a numeric **bitting code**, with **no physical key present**.
2. **Duplicator**: traces an existing key to produce a copy.

There's a second, independent dimension — whether the key is **edge-cut (edge style)** or **high-security (high-security style)** — which decides what machine and tooling you need.

One line: **lost the key but know the code → use a code machine; have the key and need a backup → use a duplicator.** The two are nearly non-interchangeable, and a professional locksmith usually needs both.

---

## Dimension One: Origination vs Duplication

### Origination (Code Machine)

Cuts an original key from a numeric code, with **no physical key needed**. Suited to "all keys lost but the lock has a code on record" scenarios.

Three types:

| Type | Principle | Characteristic |
|---|---|---|
| **Manual** | Hand-turn a dial, cut depth by depth | No computer, decades-old, cheap |
| **Automatic** | Software-controlled cutting | Precise, low-effort, handles complex cuts |
| **Punch** | Stamped/formed | Suited to bulk same-spec keys (e.g., master key systems) |

### Duplication (Duplicator)

Traces an existing key to copy it. **Fast and simple, but requires a physical key.** Nearly all standard key blanks can be duplicated.

**The key distinction**: a code machine cuts an original key (slow work), while a duplicator can't cut from code at all — so professionals usually keep both.

---

## Dimension Two: Edge Key vs High-Security Key

| Key type | Representative blank codes / models | Machine needed |
|---|---|---|
| **Edge style** | SC1, KW1, H75, Y11 | Standard key machine (both origination & duplication) |
| **High-security** | HO01, LEX90, B119 | Machine supporting high-security profiles |

High-security keys usually have **side-milled** or **laser-cut** profiles, requiring machines that support the corresponding cutter type and tool path.

---

## Key Blanks: The Pre-Cutting Step

Cutting isn't the first step — **choosing the right key blank** is. A key blank is the uncut metal key body; its:

- **keyway** (the profile of the grooves): decides whether it can be inserted into a given lock;
- **shoulder / blade / bow**: all standardized.

Common residential blanks: Kwikset (KW1), Schlage (SC1), Yale (Y1), Weiser (WR5).

**Blank-selection rule**: test-insert the blank before cutting to confirm it slides smoothly into the plug — if it won't go in or binds, you've picked the wrong keyway. This step saves significant waste and time.

## The Author's Take

**My judgment: in key cutting, the beginner rarely gets stuck on "can't cut" — they get stuck on "didn't distinguish origination from duplication, and didn't pick the right blank."** Three points:

1. **Origination and duplication are two businesses, not one "do-it-all" machine** — a code machine cuts originals very slowly, and a duplicator can't cut from code. Expecting one machine to cover both usually means it does neither well.
2. **High-security keys are a separate ecosystem** — if you serve automotive or commercial high-security locks, you need to budget for machines supporting side-milled/laser profiles; that's a major line item.
3. **Blank selection is more fundamental than cutting** — pick the wrong blank and a perfectly-cut key is still scrap. Learn to read the keyway and select the blank before chasing cutting precision.

(This is professional judgment based on locksmith key-cutting industry practice and machine-classification norms, not empirical testing.)

## FAQ

**What's the difference between a code machine and a duplicator?**
A code machine cuts an original from a numeric code with no physical key; a duplicator traces an existing key. Different tasks — professionals usually need both.

**What is a key blank?**
An uncut key metal body with a specific keyway profile. Selecting the right blank is the critical pre-cutting step.

**Do high-security keys need a special machine?**
Yes. Side-milled/laser profiles need a machine supporting the corresponding cutter and tool path.
